# Database Setup Instructions

## Prerequisites
- SQL Server Management Studio (SSMS)
- MSSQL Server 2016 or higher

## Steps

1. Open SQL Server Management Studio
2. Connect to your MSSQL Server
3. Copy and paste the SQL scripts from `database-schema.sql`
4. Execute all scripts in order
5. Verify tables are created

## Database Details
- Database Name: `employee_management_db`
- Tables: Users, Departments, Positions, Employees
